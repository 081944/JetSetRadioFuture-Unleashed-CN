# 0.6.6-cn.2：正式版可选性能叠层

在 [0.6.6-cn.1](https://github.com/081944/JetSetRadioFuture-Unleashed-CN/releases/tag/v0.6.6-cn.1) 的 Vulkan、双屏地图与实时换人基础上，加入正式版性能显示开关。Android versionCode 为 **42**。

- 点击左上角齿轮，切换“性能叠层”即可显示 FPS、Frame 帧间隔、CPU-frame 与 GPU 耗时，耗时单位为毫秒。
- 首次安装正式版默认关闭；开关立即生效并保存，下次启动保留选择。开发测试包中旧的开启状态不会自动带入正式版。
- GPU 数据不可用时显示 n/a，不以 CPU 时间冒充 GPU 时间。
- 仍为不可调试的 Release 包，原生库去除调试符号，Android 调试属性入口及 profiler 日志保持关闭。
- 沿用相同包名与签名，可覆盖 41 版或此前测试版，保留资源、存档与设置。

双屏地图、地名/目标走马灯、两列头像与碰撞初始化保持上一版行为。极少数换人异常腾空及其他限制见 [上一版说明](0.6.6-cn.1.md)。主要实机验证设备为 AYN Thor，Android 10 及以上、ARM64，需要支持随包 Turnip 的 Adreno GPU。首次运行需自行提供受支持的中文版 ISO。

感谢 [JuMatt 和上游贡献者](https://github.com/JuMatt/JetSetRadioFuture-Unleashed)。附件仅提供 APK 与 SHA256，不提供游戏镜像或独立资源。
