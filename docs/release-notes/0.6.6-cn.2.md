# 0.6.6-cn.2：中文选项菜单与性能显示

在 [0.6.6-cn.1](https://github.com/081944/JetSetRadioFuture-Unleashed-CN/releases/tag/v0.6.6-cn.1) 的 Vulkan、双屏地图与实时换人基础上，加入正式版性能显示开关。Android versionCode 为 **42**。

- 选项主菜单、子菜单、地图选择、按钮及操作说明中文化；地图名称与已有汉化资源一致。
- 点击左上角齿轮，可分别开关“显示帧数（FPS）”和“显示 CPU/GPU 耗时”。帧数开启时同时显示帧间隔，耗时以毫秒为单位。
- 首次安装正式版默认关闭；两个开关立即生效并保存，下次启动保留选择。兼容此前正式版的性能叠层设置，开发测试包中旧的开启状态不会自动带入正式版。两项均关闭时停止性能采样。
- CPU 数据为游戏/渲染线程每帧占用的处理器时间；GPU 数据为每帧渲染耗时。不可用时显示 `--`，等待 GPU 计时结果时显示 `…`。
- 仍为不可调试的 Release 包，Android 调试属性入口及 profiler 日志保持关闭。游戏主库、SDL2 和 Turnip 驱动已剥离调试符号；4 个 AdrenoTools 辅助库仍保留调试符号。
- 沿用相同包名与签名，可覆盖 41 版或此前测试版，保留资源、存档与设置。

双屏地图、地名/目标走马灯、两列头像与碰撞初始化保持上一版行为。极少数换人异常腾空及其他限制见 [上一版说明](0.6.6-cn.1.md)。主要实机验证设备为 AYN Thor，Android 10 及以上、ARM64，需要支持随包 Turnip 的 Adreno GPU。首次运行需自行提供受支持的中文版 ISO。
