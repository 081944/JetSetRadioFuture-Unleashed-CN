# 0.6.6-cn.1：Vulkan、双屏地图与实时角色切换

感谢 [JuMatt 和上游贡献者](https://github.com/JuMatt/JetSetRadioFuture-Unleashed)。本版汇总了当前 CN 分支在 AYN Thor 上的优化和双屏功能，Android versionCode 为 **41**。

## 本版变化

- **Vulkan 正式启用**：默认使用随包 Turnip 驱动，无需 ADB 调试属性。修复反向深度路径，解决远处建筑在转动视角时闪烁的问题。
- **性能优化**：优化 guest 寄存器 TLS、Vulkan uniform/绘制热路径和帧节奏等待；没有提高 CPU 频率或修改设备性能配置。
- **常驻副屏地图**：正常游玩时同步玩家位置、标记、地图地名和当前任务；隐藏原暂停界面的右侧菜单。支持触摸旋转、缩放和双击复位，旋转角度限制为 35°，避免翻转及绕屏幕法线扭转。
- **双屏布局**：地图中心稍向左移，区域名放大并左对齐，格子背景左亮右淡。任务横条保留游戏资源的雪花效果，任务文字按屏幕刷新平滑向左循环。
- **直接点击头像换人**：只显示已解锁角色，头像直接在内存读取游戏资源，不附带独立提取图片。右下角双列气泡头像，每列最多显示 5 个，更多角色可上下滑动。
- **稳定性及操作**：修复切后台后黑屏和偶发顶部黑边，保留宽屏和实体手柄支持；补充换人时的碰撞轨迹初始化。

## 正式包与安装

- APK 使用 Release 优化编译、去除调试符号、禁止 Android 调试；关闭性能叠层及 Android 调试属性入口，保留正常启动/错误日志用于排错。
- 沿用已有包名和签名，可覆盖测试包和旧版，保留游戏资源、存档与设置。
- Android 10 及以上、ARM64；需要支持随包 Turnip 的 Adreno GPU。当前主要验证设备为 AYN Thor，其他 GPU 尚未验证。
- 首次使用需自行提供受支持的中文版 ISO，应用内导入；更新后无需重新提取。无副屏时仍可正常使用主屏。
- Release 只提供 APK 和 SHA256 校验文件，不提供游戏镜像、独立资源或签名密钥。

## 验证与已知限制

- 开发阶段已验证实体手柄、宽屏、双屏地图及后台恢复；用户确认远景闪烁消失。
- 换人状态机、guest 调用桥、头像映射/解码、地图资源及 Vulkan uniform 回归通过。走马灯在设备采样中达到约 60 Hz 更新。
- 实时换人仍可能极少出现异常腾空，本版保留目前实现；不保证空中、磨轨等动作连续衔接。
- 已知任务映射显示中文，未映射任务可能显示游戏英文。当前存档只解锁少数角色，全部角色的双列长列表尚未完整实机验收。
- 设备反馈不代表完整通关或所有设备兼容。
