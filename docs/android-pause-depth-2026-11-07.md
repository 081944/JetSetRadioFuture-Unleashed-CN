# Android 暂停样式与 Vulkan 远景深度

36 版下屏区域名改为独立居中、深蓝色粗斜体；任务目标改为上方灰色横条、白色斜体，超长文字横向滚动。横条从用户游戏 SprNorm.dat 的纹理 1 直接解码原版灰色颗粒区域，不复制或打包游戏图片，不落地头像/横条图片文件。保留已有地图内部地名及右侧头像按钮。

Vulkan 后端已有 D32_SFLOAT_S8_UINT 深度附件，但 Nv2aGfx.zrev 回调为空，使共享前端的反向深度矩阵行、比较函数和清屏反转一直未启用。传统 Z 的远景深度集中在 1 附近，GPU 浮点变换和光栅化会丢失相邻建筑表面的排序。详见 NVIDIA 官方深度精度说明 https://developer.nvidia.com/blog/visualizing-depth-precision/ 。

新增 Vulkan 反向深度能力声明。共享前端负责反向矩阵行、比较与偏移符号和清屏；后端新附件初始化深度改为 0。着色器转换仅在源使用 GL [-w,w] 深度时进行重映射，避免已生成 [0,w] 的反向深度再经过一次有精度损失的转换。显式写 gl_FragDepth 的 W-buffer 片元同步反转，防止比较方向不一致。保留 RECOMP_GL_ZREV=0 原有诊断开关。

设备自检新增两组实际 GPU 绘制：距离 3000 和 3000.25 的近共面三角形，以及 W-buffer 10/20 深度排序，均要求后画的远层不能覆盖近层。只有 RECOMP_VK_GAME_TEST=1 时运行，不进入正常游戏帧循环。

Java 和 CN 原生编译通过，原有 Vulkan uniform 测试通过；原版横条资源校验为 512×40 不透明灰色颗粒，亮度对比范围 140。未调整 CPU 频率、渲染分辨率、远裁剪距离或场景模型。

36 版已覆盖安装并启动。AYN Thor 实际 GPU 自检的 distant Z 与 W-buffer 均 PASS（近层像素 255,0,0）；游戏日志确认 Vulkan 使用 reversed, 32-bit float，场景仍正常呈现。截图核验下屏原版灰色纹理横条、居中深蓝区域名、地点名与头像按钮。用户回到原远景大楼场景转动视角后反馈：闪烁消失了。调试属性已清除，正常启动不执行 GPU 自检；没有改 CPU 设置或游戏存档。APK SHA256：2d903736d154017fcc4983382acaaf7006974c182f41e1311b0a929c875c38a3。

## 第 37 版：动态雪花与左对齐地名底纹

以用户保持打开的上屏暂停截图为参考（37-upper-reference.png），确认目标横条有持续变化的雪花，地名背后有青绿色像素格及亮色横线。原有 36 版只画静态灰纹理和裸地名，不完整。

下屏目标横条以 30 Hz 切换原版噪声纹理的 UV 位置，持续呈现雪花变化。复用 BitmapShader 与 Matrix，不逐帧读取/解码资源，不生成图片文件。地名背景直接读取 SprNorm.dat 纹理 0 中的原版 80×30 像素格区域，重复铺设并在右边以 alpha 渐隐；名称及底纹左侧与任务横条对齐，文字留 8 个参考像素的内边距。保留 36 版远景深度修复。

原版资源读取校验、Android Java 和 CN 原生编译通过。游戏资源仍从用户游戏目录实时读取并在内存解码，没有将横条或地名背景图片加入 APK。

37 版已覆盖安装。真机连续截图核验任务横条噪声发生变化，地名带原版像素格底纹、与横条左侧对齐。截图为 build/logs/character-switch/37-lower-a.png 与 37-lower-b.png。

## 第 38 版：任务文字持续走马灯

任务横条与区域地名底纹共用参考坐标 x=48，文字起点共用 x=56。所有任务文字（包括短文本）持续以参考坐标每秒 50 像素从右往左循环，裁剪于固定横条内；双副本间距至少一个横条宽度，保留游戏资源动态雪花与地名底纹。Android Java 编译通过，38 版设备连续截图白色文字边界由 x=633..951 变为 x=495..813，确认整体向左 138 像素。地名保持左侧静止，角色切换修复详见角色文档第 38 版。

## 第 39 版：地名放大、镜像渐变与流畅走马灯

对照用户打开的上屏暂停地图（39-upper-ref.png），原版标题底纹是连续细格子、带一条亮色横线。按用户后续要求，下屏采用左右镜像的渐变：左侧清晰、右侧渐隐，标题仍左对齐。字号由 22 增至 27 个参考像素，底纹高度 26 增至 34、宽度至少 320。直接从用户 SprNorm.dat 读取格子内部像素，在内存组成一次性缓存的连续底纹，避免重复原图自带的渐变及图集边缘；没有图片落地或新增 APK 游戏图片资源。

滚动原先用 postInvalidateDelayed(33)，会产生约 30 Hz 更新及定时器与屏幕刷新错位。改为生命周期约束的 Choreographer 帧回调，以帧时间推进位置，启用亚像素文字；噪声仍独立以约 30 Hz 变化。移除标题每帧 saveLayer / DST_IN 的离屏混合，渐变预先合入内存底纹。窗口不可见或卸载时取消帧回调；目标为空时不持续刷新。
