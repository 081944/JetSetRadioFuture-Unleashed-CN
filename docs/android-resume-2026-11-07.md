# Android 前后台恢复与副屏触摸修复

## 原因与修改

- Android 返回前台会替换 Surface / ANativeWindow。Vulkan 原实现一直使用启动时的窗口，且把 OUT_OF_DATE / SURFACE_LOST 当作永久失败，导致游戏仍运行但主屏黑屏。
- Activity 的 Surface 回调发布持有引用的窗口；呈现线程在队列空闲后仅重建 Surface、交换链、图像视图及同步对象，保留游戏纹理、渲染目标和管线。后台无窗口时停止呈现，窗口失效错误允许重试。
- 30 版真机连续三次 Home → 返回均保持同一进程恢复画面，但截图抓到顶部 55 像素黑条。日志曾出现 1920×1025 的过渡 Surface，UI 层级保留 statusBarBackground [0,0][1920,55]。31 版在恢复和获得焦点时重新应用全屏布局及系统栏隐藏，并清除系统栏背景色；Android 11+ 使用 WindowInsetsController。
- 副屏拖动改为在摄像机坐标中累积旋转，再乘以地图默认旋转。道玄坂默认约 90° 的滚转不再交换手势轴，保留用户要求的水平反向、缩放和双击复位。

## 验证记录

- NDK 原生与 Android Java 编译通过，git diff --check 通过。
- 30 版三次前后台循环，PID 始终为 4352；交换链恢复为 1920×1080，游戏与副屏正常显示。该轮同时复现状态栏黑边，因此继续修复为 31 版。
- 日志和截图保存在忽略目录 build/logs/android-resume/。
- 不修改 CPU 频率、调度策略或游戏存档；不提交测试用游戏资源。
